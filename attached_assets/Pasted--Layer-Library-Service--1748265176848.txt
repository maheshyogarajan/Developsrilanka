| Layer                              | Library / Service                                                                                                                                          | Why it fits                                           |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **Text & layout extraction**       | `pdfplumber` for text + coords                                                                                                                             | Keeps per-char x-y that later drives UI highlights.   |
| **Table reconstruction**           | `Camelot` (lattice/stream) with quality metrics                                                                                                            | Drops low-accuracy tables automatically.              |
| **OCR fallback (scans)**           | Choose one cloud model: AWS Textract sample pipeline , Azure Document Intelligence Bank-Statement model , or Google Document AI BANK\_STATEMENT\_PROCESSOR | Handles noisy, image-only statements.                 |
| **Semantic layout disambiguation** | Hugging-Face `LayoutLMv3` for column/row labels                                                                                                            | Helps when headers repeat or break across pages.      |
| **Rule engine for validation**     | `durable_rules` micro-framework                                                                                                                            | Centralises “reject / accept” logic and logs reasons. |
| **Lineage catalog**                | Postgres + OpenMetadata lineage tables                                                                                                                     | Lets UI drill from row → PDF snippet for audits.      |
| **Security**                       | Postgres Row-Level Security (RLS) patterns                                                                                                                 | Masks PII for non-privileged users.                   |
